# Need for Speed: Hot Pursuit 2

C++ source project for Need for Speed: Hot Pursuit 2. Requires the original game data.

## Build

- Visual Studio 2022 with Desktop development with C++.
- MSVC v143 (14.35), clang-cl, and Windows SDK 10.0.26100.0.
- Win32 / x86, C++17, Release.

Open `nfshp2.sln`, select **Release | Win32**, and choose **Build > Build Solution**.

Output: `bin/Release/nfshp2.exe`.
